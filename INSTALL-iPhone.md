# Install Vesper on iPhone

1. Open the hosted **HTTPS** link to Vesper in **Safari**.
2. Tap the **Share** button.
3. Tap **Add to Home Screen**, then **Add**.

Vesper now opens full-screen from its home-screen icon and works offline after the first load.

**Storage notes**
- The home-screen app keeps its **own storage, separate from Safari tabs**. Data entered in Safari won't appear in the
  home-screen app (and vice versa), so pick one and use it consistently.
- To move data between them (or to another device), use **Backup → Export** in one and **Backup → Import** in the other.
- iOS may clear storage for web apps that go unused for a long time. **Export a backup regularly.**
